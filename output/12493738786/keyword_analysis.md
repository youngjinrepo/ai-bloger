## 검색 의도 분석

**"밥맛 좋은 쌀 추천"** 검색자
→ 지금 먹는 쌀에 만족 못하는 사람. 밥맛이 달라진다는 체감 포인트 필요.
→ 골드퀸3호 저아밀로스 + 누룽지향으로 설득 가능.

**"골드퀸쌀" 검색자**
→ 이미 품종 인지. 구매 적합 스토어 탐색 단계.
→ 가격·원산지·농협 인증이 결정 요소.

**"식어도 맛있는 쌀"** 검색자
→ 도시락·전날 밥 재활용 목적. 노화 느린 골드퀸3호 딱 맞음.

## 페르소나 3인

### 페르소나 A — 이현정 (44세, 주부, 경기도 거주)
**상황**: 두 아이(중학생·초등생) 밥 챙기는 것이 일상. 마트 쌀을 계속 사다 보니 밥맛이 다 비슷하다는 느낌. 한 번은 지인에게서 받은 쌀이 유독 구수하고 밥알이 달랐는데, 품종이 골드퀸이었다고 함.

**페인포인트**:
- 같은 경기미인데 브랜드마다 왜 밥맛이 다른지 모름
- 쌀 포대 상에 '상등급' 적혀있어도 막상 먹으면 퍼석한 경험
- 화성·평택 경기미가 맛있다는 말은 들었지만 어디서 사야 할지 모름

**좋은 인상이 생기는 지점**:
- "농협 인증 + 화성시 브랜드쌀" → 어머니 세대가 믿는 농협 신뢰감
- "물 10% 적게" → 구체적인 조리 팁 주면 살 것 같다는 느낌
- 아이들이 밥을 더 먹었다는 후기 → 구매 결정

### 페르소나 B — 박진호 (33세, 직장인, 서울 거주, 도시락 싸는 습관)
**상황**: 구내식당보다 직접 싼 도시락이 건강하고 저렴. 쌀밥을 밤에 지어서 아침에 도시락 통에 담음. 그런데 찬밥이 굳고 퍼석해져서 편의점 도시락 사먹는 일이 많아짐.

**페인포인트**:
- 도시락 밥이 점심때 차갑고 퍼석해짐
- 전날 지은 밥을 냉장고에 넣으면 딱딱해짐
- "밥맛 좋은 쌀" 찾아봐도 후기가 모두 따뜻한 밥 기준

**좋은 인상이 생기는 지점**:
- "취반 후 12시간 식감 유지" → 도시락 목적 직접 해결
- 골드퀸3호 저아밀로스 → 식어도 굳지 않는 과학적 이유
- 56,000원/10kg — 장기간 쓰는 쌀 10kg 가격으로 납득 가능

---

### 페르소나 C — 장미선 (38세, 다이어트 관심자, 쌀밥 못 끊음)
**상황**: 탄수화물 줄이려고 쌀밥 양을 반 공기로 줄였는데, 배가 금방 꺼져서 야식 먹는 패턴. 저당 쌀, 곤약쌀 같은 것도 알아봤지만 맛이 이상해서 포기. 밥 맛있게 먹으면서 덜 먹는 방법 찾는 중.

**페인포인트**:
- 쌀밥 줄이면 배고픔, 안 줄이면 죄책감
- 저당쌀·다이어트쌀 시도했지만 맛 이상해서 지속 불가
- 혈당 걱정 있지만 쌀은 포기 못 함

**좋은 인상이 생기는 지점**:
- 아밀로스 12.5% → 일반 쌀보다 혈당 상승 완만
- 찰기 있어 적은 양으로도 포만감 높음
- 맛있게 먹으면서 덜 먹게 된다는 경험담 → 공감
