# 키워드 분석 & 페르소나 — 새벽딴 경북 샤인머스켓

작성일: 2026-07-27
※ 검색량 수치 미사용. 자동완성 실측 + 구매평 200건 정량분석 근거.

## 1. 자동완성 실측
| 시드 | 결과 |
|---|---|
| 샤인머스캣 | **철** / **김천 샤인머스캣** / 2kg / 케이크 / **가격** / **보관방법** / **후숙** |
| 샤인머스캣 고르는법 | (단독 존재 = 실검) |
| 샤인머스캣 보관 | 보관방법 |
| 샤인머스캣 후숙 | 후숙 / 후숙하는법 |

### 신호
1. **`철`이 최상위** — "지금이 제철 맞나?"가 최대 관심. 하우스 샤인은 노지보다 이른 7~8월에 나옴 → "벌써 샤인 나왔나" 수요를 하우스가 먹음.
2. **`김천 샤인머스캣`** — 산지 브랜드가 자동완성에 고착. 이 상품(영천/김천)과 일치.
3. **`고르는법`·`보관방법`·`후숙`** — 사기 전/후 실용 정보 수요. 특히 샤인은 후숙 개념(사과·바나나와 달리 후숙 거의 안 됨)에 오해가 많음.
4. **`가격`** — 샤인은 "비싼 과일" 인식. 하우스 조기물 + 농할 50%가 가격 저항을 낮추는 지점.

## 2. 타겟 키워드
- **메인**: 샤인머스캣, 씨없는포도, 하우스샤인머스캣
- **서브**: 샤인머스캣철, 김천샤인머스캣, 샤인머스캣고르는법, 샤인머스캣보관방법
- **맥락**: 샤인머스캣택배, 제철과일, 샤인머스캣당도, 산지직송, 아이간식포도

| 의도 | 검색어 | 줘야 할 답 |
|---|---|---|
| 제철 확인 | 샤인머스캣 철 | 하우스라 지금(7~8월)부터 가능, 노지와 차이 |
| 고르기 | 고르는법 / 당도 | 좋은 샤인 판별(갈색빛=당도 증거 등) |

| 구매결정 | 가격 / 2kg / 택배 | 하우스 조기물 가성비, 크기 솔직 고지 |

## 3. 구매 페르소나 (리뷰 200건 기반)

### 페르소나 1 — "제철 첫물 샤인 먹고 싶은 사람" (여름, 조바심)
- 근거: 자동완성 `철`, 리뷰 "샤인 시즌인가 해서 주문"
- 페인: 노지 샤인은 9~10월. 여름에 벌써 먹고 싶은데 마트엔 비싸거나 없음.
- 좋은 인상: 하우스 샤인이 7~8월에 새벽 수확·당일 출고. 첫물 특유의 아삭·달콤.

### 페르소나 2 — "샤인 복불복·비싸게 사고 실망한 사람" (가성비·불신)
- 근거: 리뷰 당도 26%지만 4.63점(불만도 존재), 자동완성 `가격`·`고르는법`
- 페인: 샤인은 비싼데 싱겁거나 무르면 손해가 큼. 마트 샤인도 복불복.
- 좋은 인상: 16브릭스 표기·산지직송·농할 50%. 단 크기(하우스라 작을 수 있음) 솔직 고지에 오히려 신뢰.

### 페르소나 3 — "아이 간식/선물로 씨없는 포도 찾는 사람"
- 근거: 태그 선물용, 씨없는 포도, 리뷰 "아이가 좋아해서"
- 페인: 아이에게 씨 발라주기 번거로움. 껍질째 먹이고 싶음.
- 좋은 인상: 씨없고 껍질째 먹는 포도. 단 "간혹 씨 있을 수 있음"은 상세페이지도 고지.

## 4. 핵심 페인 3가지 (본문 필수)
1. **여름엔 샤인 못 먹는다는 통념** → 하우스 조기물, 새벽 수확 당일 출고
2. **샤인 복불복·비쌈** → 16브릭스·산지직송·농할가, 크기 솔직 고지
3. **받아보니 물러/터짐(포장 리스크)** → 수령 즉시 개봉·냉장, 보관법, 알탈락은 정상 범위 안내

## 5. 사실성 가드레일
- 포장 리스크 은폐 금지(최다 저평점). 수령 즉시 확인·냉장 안내로 전환
- 하우스=조기물이라 알 작을 수 있음 명시. "노지 대과" 과장 금지
- "무조건 달다" 금지(복불복 리뷰). 16브릭스는 "표기 기준"
- 샤인은 후숙으로 더 달아지지 않음(포도는 비후숙과일) — 정확히 안내
- 씨 있을 수 있음/갈색빛 정상 (상세 근거)
- 가격 14,900원(1kg·농할)·배송비 3,500원 별도 명시, "현재 기준"
