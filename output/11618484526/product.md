## 중요 — 이건 완제품이 아님

떠먹는 그릭요거트 완제품이 아니라, **우유에 넣어 직접 그릭요거트를 만드는 종균(스타터)**이에요.
→ 콘텐츠 각도가 "어떤 그릭요거트를 사먹나"가 아니라 **"사먹지 말고 만들어라"**로 바뀜.

## 만드는 법 (일반 방식, 조사)

1. 우유를 40~45도로 살짝 데움
2. 스타터를 넣고 잘 섞음
3. 요거트 메이커·전기밥솥 보온·따뜻한 곳에서 6~8시간 발효 (실온 방치로 만드는 후기도 있음)
4. 면보/유청 분리기로 유청을 걸러내면 → 꾸덕한 그릭요거트 완성
5. 남은 유청은 리코타치즈·요리에 활용
※ 한 팩으로 만드는 정확한 양·발효 조건은 제품 안내 참고 (수치 임의 표기 금지)

## 리뷰에서 드러난 실사용 맥락

- **전환 배경**: 예전엔 불가리스·윌 같은 시판 요구르트를 종균으로 썼는데 → 당분 걱정 + 유통기한 지나면 못 만드는 불편 → 가루 스타터로 갈아탐
- **가성비**: "그릭요거트 사먹자니 값이 만만치 않다" → 우유만 있으면 직접
- **활용**: 남은 유청으로 리코타치즈 / 다이어터는 그릭+치아씨드 한끼 대용
- **범용성**: 저지방·멸균 우유도 잘 발효됨 / 우유만 있으면 뚝딱
- "파는 거랑 맛 차이가 크다" 만족도 높음

## 핵심 강점 (콘텐츠용)

1. **완전 무가당·무첨가 가능** — 시판은 당·첨가물, 불가리스/윌 종균은 당분. 이건 순수 종균이라 우유만 넣으면 첨가물 0
2. **가성비** — 시판 그릭요거트 비쌈 → 우유값 정도로 대량 자가제조
3. **상온 보관 파우더** — 시판 요구르트 종균처럼 유통기한 쫓길 필요 없음
4. **꾸덕함 조절** — 유청 거르는 정도로 내 취향대로
5. **부산물 활용** — 유청으로 리코타치즈

## 시기성

- 여름 다이어트·건강 간편식 수요
- 홈메이드·무첨가 관심 증가 트렌드

## 타겟 페르소나

1. 시판 그릭요거트 값 부담에 직접 만들기 관심 있는 사람
2. 불가리스·윌로 요거트 만들다 당분·유통기한에 불편 느낀 사람
3. 아이 간식으로 무첨가 요거트 주고 싶은 부모
4. 그릭+토핑 한끼 대용하는 다이어터
