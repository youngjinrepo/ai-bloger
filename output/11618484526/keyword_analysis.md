# 키워드 분석 — 아임뉴트리 그릭요거트 스타터 (11618484526)

## 유입 각도

"그릭요거트 완제품 고르기"가 아니라 **"직접 만들기"** 쪽 검색 수요를 잡는 게 핵심.
이쪽이 오히려 정보 탐색이 깊고(만드는 법·종균·발효·유청) 블로그 유입에 유리.

## 검색 의도

**"그릭요거트 만들기"** → 이미 만들 의향. 종균 뭘 쓸지 탐색 → 이 제품 정확히 대응
**"불가리스로 요거트 만들기"** → 시판 요구르트로 만들던 사람. 당분·유통기한 불편 짚으면 전환
**"그릭요거트 사먹기 vs 만들기"** → 가성비 비교 원함. 우유값 계산이 결정타

## 페르소나 3인

### 페르소나 A — 정미영 (43세, 주부, 아이 간식)
**상황**: 아이한테 요거트 자주 주는데 시판은 당이 너무 많아 걱정. 예전엔 불가리스 사서 우유에 넣어 만들었는데 그것도 당분이 있고, 유통기한 지나면 종균으로 못 써서 번거로웠음. 무첨가로 아이한테 주고 싶음.

**페인포인트**:
- 시판 요거트 당분 걱정 (아이 간식)
- 불가리스 종균도 당분 + 유통기한 압박
- 첨가물 없는 걸 먹이고 싶음

**좋은 인상**:
- 순수 종균이라 우유만 넣으면 완전 무첨가
- 파우더라 상온 보관, 유통기한 쫓길 필요 없음
- 아이가 잘 먹고 만들기 간편

### 페르소나 B — 김하늘 (29세, 다이어터, 그릭 한끼 대용)
**상황**: 아침·한 끼를 그릭요거트+토핑(치아씨드·과일)으로 대체 중. 근데 무가당 그릭요거트 사먹으니 값이 부담. 매일 먹으니 한 달 요거트값이 은근 큼. 직접 만들면 싸다는 걸 알게 됨.

**페인포인트**:
- 매일 먹는데 시판 무가당 그릭 값 부담
- 완제품 당·첨가물 신경
- 꾸덕함이 제품마다 들쭉날쭉

**좋은 인상**:
- 우유값 수준으로 대량 자가제조 → 가성비
- 유청 거르는 정도로 꾸덕함 조절
- 유청은 리코타치즈로 활용

### 페르소나 C — 이준서 (34세, 홈쿡 관심 1인 가구)
**상황**: 요리·발효에 관심 있고 집에서 이것저것 만들어 먹는 걸 좋아함. 그릭요거트도 사먹기보다 만들어보고 싶은데, 종균으로 뭘 써야 잘 되는지 몰라서 미뤄왔음. 실패 없이 되는 걸 원함.

**페인포인트**:
- 만들고 싶은데 종균 선택 막막
- 발효 실패 걱정
- 저지방·멸균 우유로도 될지 의문

**좋은 인상**:
- 17종 생유산균 전용 종균 → 실패율 낮음
- 저지방·멸균 우유도 발효된다는 후기
- 유청으로 리코타까지 만드는 확장성
