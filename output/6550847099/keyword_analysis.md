# 키워드 분석 — 한끼통살 소스 통 닭가슴살 (6550847099)

## 유입 각도

닭가슴살은 검색량 최상위(식품 랭킹 2위권) 상시 수요 품목. 다만 경쟁 치열 →
**차별화 훅 = "생닭 실패 → 데우면 끝 소스 통살로 전환" + "20종이라 안 질림"**

## 타겟 키워드

### 메인
- 닭가슴살 추천
- 다이어트 닭가슴살
- 소스 닭가슴살
- 데워먹는 닭가슴살

### 서브
- 안 질리는 닭가슴살
- 맛있는 닭가슴살 추천
- 도시락 닭가슴살
- 한끼통살 후기
- 닭가슴살 종류 비교

### 롱테일 (정보/전환)
- 생닭가슴살 vs 조리된 닭가슴살
- 닭가슴살 입문자 추천
- 다이어트 닭가슴살 질릴 때
- 소스 닭가슴살 살 안 쪄
- 닭가슴살 나트륨 단백질

## 검색 의도

**"맛있는 닭가슴살 추천"** → 퍽퍽·비린 닭가슴살에 질린 사람. "20종 맛"이 결정타
**"생닭 vs 조리된 닭가슴살"** → 뭘 살지 고민. "생닭은 실패율↑, 조리형이 지속" 정보
**"닭가슴살 나트륨"** → 건강 신경 쓰는 사람. 정직한 트레이드오프 서술이 신뢰

## 페르소나 3인

### 페르소나 A — 이지현 (34세, 직장인, 다이어트 3전 4기)
**상황**: 다이어트 결심할 때마다 생닭가슴살 대량 구매. 삶으면 퍽퍽하고 비려서 몇 번 먹다 냉동실에 방치. 결국 배달 음식으로 회귀. "맛없어서 못 버틴다"가 반복 실패 이유.

**페인포인트**:
- 생닭 퍽퍽·비린내로 지속 실패
- 조리(삶기·손질) 귀찮음
- 매일 같은 맛에 질림

**좋은 인상**:
- 전자레인지 데우면 끝 → 조리 장벽 해소
- 20종 맛 로테이션 → 질림 문제 해결
- 통살이라 씹는 맛·포만감 (볼/너겟과 다름)

### 페르소나 B — 박현우 (29세, 헬스 직장인, 야근족)
**상황**: 헬스 후 단백질 보충 필요한데 야근 많아 요리할 시간 없음. 편의점 닭가슴살은 개당 3~4천 원이라 매일 사기 부담. 간편하면서 가성비 있는 걸 원함.

**페인포인트**:
- 시간 없어 조리 불가
- 편의점 단품 개당 단가 부담
- 단백질은 확보하고 싶음

**좋은 인상**:
- 개당 2,470원 → 편의점보다 쌈
- 통살 100g당 단백질 약 20g
- 냉동 쟁여두고 전자레인지 2~3분

### 페르소나 C — 최수빈 (27세, 다이어트 입문, 맛 중시)
**상황**: 다이어트는 하고 싶은데 맛없는 음식은 절대 못 먹는 타입. 순수 스팀 닭가슴살은 너무 밍밍해서 시도했다 포기. 맛있으면서 살 안 찌는 걸 찾는 중.

**페인포인트**:
- 밍밍한 다이어트식 못 견딤
- 맛있는 건 살찔까 걱정
- 다이어트 지속 실패

**좋은 인상**:
- 20종 맛(불닭·왕갈비·떡볶이 등) → 맛 만족
- 100g당 약 140kcal → 죄책감 낮음
- 소스형이라 순수 스팀보다 당·나트륨 있다는 정직한 설명 → 신뢰

## 각도 요약

| 각도 | 대상 | 핵심 메시지 |
|---|---|---|
| 생닭 실패 → 전환 | 입문자 | 냉동실에 박아둔 경험 있다면 데우면 끝 소스 통살로 |
