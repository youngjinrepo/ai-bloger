| 음식물처리기 전기세 | 미닉스·쿠쿠 / **폭탄** / **누진세** |

### 읽어낸 신호
1. **카테고리 진입 검색이 전부 "고민·불신"으로 시작** — 단점, 냄새, 곰팡이, 전기세 폭탄, 관리. 사기 전에 겁먹은 사람이 검색함.
2. **방식 갈림길이 핵심 축** — `분쇄`(건조분쇄) vs `미생물`. 이 둘의 비교가 카테고리 최대 검색 의도.
3. **`미생물 음식물처리기 흙`·`냄새`** — 미생물식의 최대 궁금증이자 불안: "흙냄새 난다던데?" → 이걸 정면으로 다루는 게 무기.
4. **`전기세 폭탄`·`누진세`** — 건조식의 대표 페인. 미생물식(가열 안 함)의 반사이익 지점.
5. **`린클 이지 비교`·`프라임 차이`** — 린클 라인업 내부 비교 수요 존재 → 이지/그래비티 대비 프라임S 위치 설명 필요.
6. **`렌탈 지원금·현금`** — 음식물처리기는 지자체 보조금이 큰 변수. (금액은 지역별 상이 → 단정 금지, "지자체 확인" 안내)

## 3. 구매 페르소나 (리뷰 240건 + 커뮤니티 기반)

### 페르소나 1 — "여름철 음쓰 냄새·초파리에 항복한 사람" (30~40대, 주 타겟)
- **근거 리뷰**: "음쓰 버리러 나가는 횟수가 크게 줄어", "봉투·종량제에서 해방", "초파리 때문에"(경쟁 블로그 제목에도 등장)
- **페인**: 여름엔 하루만 지나도 싱크대 거름망에서 냄새·날파리. 음쓰통 들고 엘리베이터 타는 게 스트레스.
- **좋은 인상**: 뚜껑 닫으면 냄새 없음. 그때그때 바로 투입, 버리러 나갈 일 자체가 사라짐.

### 페르소나 2 — "건조식 전기세·소음에 데인 사람 / 방식 고민 중" (30~50대)
- **근거 리뷰**: "예전 가열분쇄식은 내솥 7만원·필터 2만원", "수증기 많아 필터 수명 짧음", "누룽지처럼 눌어붙음", 자동완성 `전기세 폭탄`
- **페인**: 건조식은 돌릴 때마다 전기세 걱정, 소음, 소모품 교체비. 김치·국물은 되는데 유지비가 무섭다.
- **좋은 인상**: 미생물식은 가열 안 해서 전기세 적고 필터 1년 1회. 소음이 "냉장고 수준". 유지비 총액에서 역전.

### 페르소나 3 — "미생물식이 궁금한데 관리가 겁나는 사람" (신중형)
- **근거 리뷰**: 자동완성 `미생물 흙 / 곰팡이 / 관리 / 만들기`, "초기엔 탄수화물 위주로"
- **페인**: 균을 키운다는 게 낯설다. 곰팡이 안 나나? 흙냄새 심하지 않나? 관리 복잡한 거 아냐?
- **좋은 인상**: 냄새는 발효취(흙·톱밥·구수한)라 음쓰 악취와 다름. 그때그때 넣기만 하면 되고 4중필터·UV로 관리 부담 낮음.

### (보조) 선물 수요 — 태그에 어버이날선물, 리뷰에 "부모님·생일선물". 부모님 댁 음쓰 고생 덜어드리는 선물.

## 4. 핵심 페인 포인트 3가지 (본문 필수)
1. **여름 음쓰 = 냄새·초파리·버리러 나가기** → 미생물 발효 + 4중필터, 버릴 일 자체가 줆
2. **건조식 전기세·소모품 부담** → 가열 안 하는 미생물식, 필터 1년 1회(+2년치 증정)
3. **미생물 관리 불안(흙냄새·곰팡이)** → 냄새 정체 설명(발효취), 넣기만 하면 되는 운용

## 5. 사실성 가드레일 (지어내면 안 되는 것)
- 소음 "무소음" 단정 금지 — 밤엔 들린다는 리뷰 있음
- 크기 "작다" 금지 — "너무 크다"가 대표 단점. 2~3인 적정
- 냄새 "전혀 없다" 금지 — 뚜껑 열면 발효취 있음
- 벌레 이슈 은폐 금지 — 1점 리뷰 존재. 일반화도 금지(다수는 무관)
- 전기세·유지비는 "가열식 대비 낮음"까지만. 구체 금액 단정 금지
- 보조금은 "지자체별 상이, 확인 필요"로만
- 가격 658,000원(즉시할인 43.2만 적용)은 변동 가능 → "현재 기준" 명시
- 미생물 분해가 "질병 예방/친환경 효과" 등으로 과장 금지
