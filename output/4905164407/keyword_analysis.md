# 키워드 분석 — 생활공작소 대용량 제습제 24개 (4905164407)

## 유입 각도 (블로그 최적)

제습제는 **정보 탐색 수요가 강한 품목**이라 블로그 유입에 유리해요.
사람들이 사기 전·후로 검색하는 것: "어디에 두나", "언제 교체하나", "곰팡이 없어지나", "실리카겔이랑 뭐가 다르나". → 정보 제공형 콘텐츠가 유입을 만든다.

## 타겟 키워드

### 메인 키워드
- 제습제 추천
- 대용량 제습제
- 옷장 제습제
- 장마철 습기제거

### 서브 키워드
- 제습제 두는 위치
- 제습제 교체 시기
- 신발장 습기제거제
- 곰팡이 예방 제습제
- 제습제 가성비

### 롱테일 (정보 탐색 = 유입 핵심)
- 제습제 어디에 둬야 효과적
- 제습제 물 차면 교체
- 염화칼슘 제습제 원리
- 옷장 습기 아래 위 어디
- 제습제 곰팡이 없어지나

## 검색 의도 분석

**"제습제 두는 위치"** 검색자
→ 이미 샀거나 살 사람. "아래칸 안쪽 구석" 정보가 결정타.

**"제습제 교체 시기"** 검색자
→ 언제 갈아야 할지 궁금. "물 차거나 굳으면, 1~2개월" + 방치 시 유해가스 경고가 신뢰.

**"곰팡이 예방 제습제"** 검색자
→ 곰팡이 고생 중. "제습제는 곰팡이를 없애는 게 아니라 예방" 정직한 정보가 오히려 신뢰.

## 페르소나 3인

### 페르소나 A — 정혜숙 (46세, 주부, 붙박이장 곰팡이)
**상황**: 장마철만 되면 안방 붙박이장에서 눅눅한 냄새가 난다. 작년엔 아끼는 코트 어깨에 곰팡이가 피어서 버렸다. 제습제를 넣긴 하는데 어디에 둬야 효과적인지, 언제 갈아야 하는지 잘 몰라서 대충 위칸에 하나 던져둔다.

**페인포인트**:
- 옷장 눅눅함·냄새, 옷에 곰팡이 핀 경험
- 제습제를 넣어도 효과가 없는 것 같음(위치를 몰라서)
- 언제 교체해야 하는지 감이 없음

**좋은 인상**:
- "습기는 아래부터 → 아래칸 구석에" 정보로 왜 효과 없었는지 납득
- 24개입이라 옷장·이불장·신발장 다 배치 가능
- 개당 871원 → 여러 개 팍팍 써도 부담 없음

---

### 페르소나 B — 김도윤 (31세, 1인 가구, 신발·현관 냄새)
**상황**: 원룸이라 환기가 잘 안 되고, 신발장·현관에서 꿉꿉한 냄새가 난다. 장마철엔 방까지 눅눅한 느낌. 유명 브랜드 제습제는 개당 2천 원이라 여러 개 사기 부담스러워서 하나만 놓고 버텼다.

**페인포인트**:
- 원룸 환기 안 됨, 신발장·현관 냄새
- 유명 제습제 개당 단가 부담
- 좁은 공간이라 여러 곳에 둬야 하는데 비용

**좋은 인상**:
- 개당 871원 → 신발장·싱크대·옷장·화장실 다 둬도 부담 없음
- 대용량 24개 = 원룸 1년치
- 화장실·차량까지 되는 전방위 용도

---

### 페르소나 C — 이서진 (39세, 가성비 소비자, 소모품 관리)
**상황**: 제습제는 1~2개월마다 갈아야 하는 소모품이라 개당 단가에 민감. 마트에서 낱개로 사면 비싸고, 그때그때 사는 게 번거롭다. 한 번에 대용량으로 쟁여두고 쓰고 싶다.

**페인포인트**:
- 소모품이라 개당 단가가 누적 비용
- 낱개 구매 번거로움
- 브랜드 프리미엄에 돈 쓰기 싫음

**좋은 인상**:
- 정상가 6만 원 → 20,900원(65%), 개당 871원 = 대용량 직구 수준
- 리뷰 84,359개 4.84점 → 가성비인데 품질 검증됨
- 한 번 사면 오래 쓰는 쟁여두기 최적
