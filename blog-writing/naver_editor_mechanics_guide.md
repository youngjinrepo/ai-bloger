# 네이버 에디터(스마트에디터 ONE) 자동화 분석 및 구현 가이드

이 문서는 AI 블로거 프로젝트에서 네이버 블로그 에디터를 브라우저 자동화(JS 주입 및 클릭 제어)로 조작할 때 발생할 수 있는 React 상태 충돌 문제를 우회하고, 안전하게 마크다운 포맷을 에디터 네이티브 컴포넌트로 변환하기 위해 연구된 최종 가이드입니다.

## 1. 해시태그(Hashtag) 자동 입력 기법
단순히 본문에 텍스트를 `innerHTML`로 찔러 넣으면 네이버 에디터는 이를 해시태그로 인식하지 않습니다.
- **해결책**:
  1. 에디터 내부의 숨겨진 textarea(보통 `@e54`나 특정 텍스트 입력부)에 키보드 이벤트(native fill)를 발생시켜 `#태그` 텍스트를 입력합니다. (예: `bsk fill`)
  2. `[발행]` 버튼을 클릭해 모달을 띄우면, 에디터가 본문을 스크래핑하여 해시태그 영역에 정상적으로 태그를 등록합니다.
  3. 모달을 닫고(ESC 등), 본문에 입력된 해시태그 텍스트 노드의 `innerHTML = '<br>'`를 호출해 사용자 눈에 보이지 않게 본문에서만 지웁니다. 모달의 태그 상태는 유지됩니다.

## 2. 인용구(Quotes) 맵핑 및 변환
React DOM 트리에 새 노드를 강제로 삽입하면 에디터가 크래시납니다. 따라서 기존 툴바를 이용한 변환이 필수적입니다.
- **해결책 (UI 모핑 기법)**:
  1. `[인용구]` 버튼을 클릭하여 기본 인용구 컴포넌트를 생성합니다.
  2. 생성된 인용구를 클릭(포커스)하면 인용구 툴바가 팝업됩니다.
  3. 마크다운의 내용(예: 팁, 주의사항, 대화 등)에 따라 툴바의 `[인용구 스타일]` 버튼을 순차적으로 클릭해 원하는 디자인(버튼식, 포스트잇, 말풍선 등)으로 모핑(Morph)시킵니다.
  4. 이후 `innerHTML`로 텍스트를 찔러넣고 `input` 이벤트를 발생시킵니다.

## 3. 표(Table) 완벽 제어 메커니즘
가장 까다로운 컴포넌트인 표를 마크다운 표 크기에 맞게 동적으로 늘리고 줄이는 기법입니다.
- **생성 및 크기 조절**:
  - `[표 추가]` 버튼 클릭 시 기본 3x3 표가 생성됩니다.
  - **행/열 추가**: 추가가 필요한 경우, 외곽의 `[+]` 버튼(`.se-cell-add-button`)을 클릭하거나, 마지막 셀에서 `Tab` 키를 누르면 행이 추가됩니다.
  - **행/열 삭제**: 줄여야 하는 경우, 행/열 선택 버튼(`.se-cell-select-button`)을 클릭하고 `Backspace` 키를 눌러 삭제합니다.
- **서식 적용 (헤더 볼드, 가운데 정렬, 배경색)**:
  - 툴바를 이용해 서식을 적용하려 하면 React 상태 불일치로 텍스트가 사라지는 버그가 발생할 수 있습니다.
  - **직접 DOM 주입 기법**이 훨씬 안전합니다.
  - 배경색: `td.style.backgroundColor = '#f7f7f7'`
  - 정렬: `td.querySelector('p').style.textAlign = 'center'`
  - 볼드: `td.querySelector('span.__se-node').innerHTML = '<b>' + text + '</b>'`
  - 주입 후 `dispatchEvent(new Event('input', {bubbles: true}))`를 호출하면 에디터가 서식을 정상적으로 인식 및 저장합니다.

## 4. 구분선(Dividers) 및 컴포넌트 삭제 안전성
- 마크다운의 `---`는 툴바의 두 번째 구분선(`line1`)에 매핑됩니다.
- 본문 텍스트 덩어리를 삭제할 때 `Backspace` 키를 쏘면 포커스가 하단 검색창 등으로 튀어버릴 위험이 있습니다.
- 안전한 삭제: 지우고자 하는 노드의 `span.__se-node`에 `innerHTML = '<br>'`을 넣는 것이 포커스를 유지하며 가장 깔끔하게 비우는 방법입니다.

## 5. 결론 및 향후 스크립트 작성 시 주의사항
- **절대 React의 고유 속성(`data-offset-key` 등)이 포함된 구조를 통째로 덮어쓰지 말 것.**
- **데이터는 오직 `span.__se-node` 내부에만 주입할 것.**
- UI 제어가 필요한 경우 JS로 `mousedown`, `click` 이벤트를 발생시키고, 이로 인해 버그가 나는 서식(표 헤더 등)은 CSS `style` 속성을 직접 제어할 것.
