질의: "우니 홈마카세 후기", "냉동우니 해동", "성게알 내돈내산"

## 1. 문장이 짧다 (제일 큰 차이)

**문장 길이 중앙값 17자.** 하위 10%는 6자, 상위 10%도 36자.

AI가 쓰면 30~50자 문장이 고르게 이어지는데, 실제 글은 들쭉날쭉하고 짧은 게 훨씬 많다.

```
참치 등장. 단새우 등장. 우니 등장. 안키모 등장.
우니.. 녹진했다
링크첨부! 내돈내산 인증
```

> **규칙**: 한 문단에 6~10자짜리 문장을 최소 하나 섞는다. 길게 쓴 문장 뒤엔 짧게 끊는다.

---

## 2. 종결어미 1위는 "~더라고요" (24편에 41회)

압도적 1위. 그 뒤로 "~같아요"(19), "~이었어요"(17), "~있어요"(11), "~좋았어요"(9).

단정하지 않고 **내가 겪어보니 그렇더라**로 흘리는 게 핵심.

```
조금 아쉽더라고요
집에서 먹는데도 제법 홈마카세 느낌이 나더라고요
시작부터 젓가락이 계속 가더라고요
근데 여기서 많이들 놓치는 해동의 비밀이 하나 있더라고요
```

> **규칙**: "~습니다/~해요"로 단정하는 문장 중 3분의 1은 "~더라고요"로 바꾼다.

---

## 3. 정서 기호는 ㅠㅠ보다 느낌표

글당 사용 횟수:

| 기호 | 글당 | 비고 |
|---|---|---|
| **!** | **3.9회** | 압도적 1위 |
| ... | 2.2회 | 말끝 흐리기 |
| ? | 1.8회 | 독자에게 묻기 |
| ~ | 1.5회 | 어미 늘이기 |
| 이모지 | 1.2회 | |
| ㅎㅎ | 0.7회 | |
| ㅋㅋ | 0.6회 | |
| **ㅠㅠ** | **0.4회** | 생각보다 적다 |

> **규칙**: 2,000자 글이면 ! 4개, ... 2개, ? 2개, ~ 1~2개. ㅠㅠ는 1~2개면 충분.

## 4. 자주 쓰는 부사 (AI가 잘 안 쓰는 것들)

정말 36 · 진짜 35 · 너무 29 · **딱 29** · **살짝 24** · **그냥 20** · **생각보다 18** · **막 14** · 역시 8 · 완전 7

"살짝", "딱", "막", "생각보다", "그냥"이 특히 많이 쓰인다.

```
사시미는 살짝 못 본척 해쥬시고
감태 싸서 한 입 딱 넣으면
```

## 5. 이 카테고리 핵심 어휘

신선 48 · **비린 27** · 녹진 21 · 탱글 18 · 고소 15 · 풍미 12 · 달큰 11 · 부드럽 11 · 감칠 8 · 쓴맛 7 · 크리미 6

## 6. 도입부 공식

거의 모든 글이 같은 순서를 탄다.

```
① 상황 고백 ("요즘 ~가 먹고 싶더라고요", "집들이를 할 예정이랍니다")
② 밖에서 먹으면 비싸다는 불만
③ 그래서 집에서 시켜봤다
④ 여러 곳 비교했다는 언급
```

실제 사례:

```
밖에서 먹으면 너무 비싸요ㅋㅋㅋㅋ 새우 몇 마리 나오고
우니 조금 올라가 있는데 가격 보면 갑자기 정신이 번쩍 듦...

오마카세 한 번 가려면 예약부터 막막하죠-
집에서 비슷하게 회 세트를 찾아보면 이번엔 뭘 골라야 할지가 막막해지고요.

요즘 방어 철이라 방어회가 너무 너무 먹고 싶더라고요 ㅠㅠ
근데 횟집 가자니 가격이 부담되...
```

## 7. 해동 관련 실제 표현

```
우니는 냉장고에서 6~12시간 정도 해동하는 방법이 안내되어 있었는데,
저는 당일 급하게 먹기로 해서 흐르는 물에 해동했어요
→ 시간이 충분하다면 안내된 방법대로 미리 냉장 해동해서 드시는 게 좋을 거 같아요

해동 시 나오는 수분은 키친타월로 가볍게 제거
해동 후 재냉동은 식감 손상의 원인이 됩니다
우니는 나무젓가락을 사용!
```

※ "6~12시간"은 타 판매처 안내값. 우리 상품 상세페이지 기준이 아니므로 그대로 인용하지 말 것.

## 8. 내가 말해놓고 내가 밑줄 긋지 마라 (북치고 장구치고)

AI가 제일 티 나는 습관. 지시문을 던져놓고 **독자가 못 알아들었을까 봐 한 번 더 도장을 찍는다.**
정작 앞 문장은 이미 완결돼 있어서 덧붙일 게 없다. 사람은 그냥 다음 얘기로 넘어간다.

| 이렇게 쓰면 | 뭐가 문제냐면 |
|---|---|
| 전날 밤에 냉장실로 옮기세요. **이게 정답이에요.** | 방법 말하고 또 평가함 |
| 덜 풀리면 식감이 안 나와요. **완전히 풀렸을 때가 진짜입니다.** | 같은 말 두 번 |
| 전날 밤에 냉장실로 옮기기. **이거 하나면 됩니다.** | 또 도장 |
| 소제목 "해동, 이게 8할" → 본문 **"해동에서 갈립니다"** | 소제목이 한 말 반복 |
| 소제목 "받고 놀랄 수 있는 것들" → **"놀라지 마세요"** | 위와 같음 |
| 리스트 바로 앞에 **"이 정도예요"** | 리스트가 알아서 말해줌 |

블랙리스트 표현:

```
이게 정답이에요 / 이거 하나면 됩니다 / 이게 핵심입니다
~가 진짜입니다 / 이 정도예요 / 결론은 ~입니다
제일 궁금한 게 이거잖아요
```

> **규칙**: 볼드로 지시문을 쓰면 **바로 다음 문장에는 새 정보만** 넣는다.
> 소제목에 쓴 말은 본문 첫 문장에서 다시 쓰지 않는다.

---

## 9. 자랑할 때 리뷰 인용하지 마라

좋다고 주장할 때 후기를 끌어오면 **남의 말**이 된다. 내가 겪은 것처럼 한 줄로 말하는 게 훨씬 세다.
이유 설명("~하거든요")도 대부분 뺄 수 있다.

```
✗ 손님 올 때는 상이 확 삽니다. 목판에 올려두면 모양이 그럴듯하거든요.
  리뷰에도 "우니 전용 판까지 구매했더니 여느 이자카야 못지않았다"는 후기가 있더라고요.

○ 손님 올 때도 좀 있어보이고, 색다른 메뉴라 반응도 좋더라구요.
```

단, **단점을 말할 때의 인용은 근거가 되므로 예외.** (단점 섹션을 쓰는 경우에 한함)

## 10. 부연·단서는 괄호로

정보는 남기되 본문 흐름을 끊지 않는다.

```
✗ 100g이면 대략 열 조각 안팎이에요. 근데 개수를 세서 담는 게 아니라
  중량 기준이라, 알 크기 따라 그때그때 살짝 달라지더라고요.

○ 100g이면 대략 열 조각 안팎이에요.
  (개수를 세서 담는 게 아니라 중량 기준이라 그때그때 살짝 달라집니다)
```

## 11. 문장을 쪼개는 게 아니라 할 말을 줄이는 것

"문장 중앙값 17자"를 지키겠다고 짧은 문장을 **여러 개** 만들면 안 된다.
실제로는 3문장을 1문장으로 합치고 나머지를 버린다.

```
✗ 집들이나 연말 모임에 올리는 분들이 많고요.
  단새우나 감태 같이 시켜서 곁들이는 조합이 제일 인기입니다.
  캠핑 가서 고기 구우면서 한 점씩 먹는다는 분도 있었어요.

○ 집들이나 연말 모임, 캠핑에도 안 어울리는 데가 없습니다.
```

관용구를 쓰면 설명이 통째로 필요 없어진다. ("참 쉽죠?", "안 어울리는 데가 없습니다")

---

## 12. 적용 체크리스트

- [ ] 문단마다 10자 이하 문장이 하나씩 있는가
- [ ] "~더라고요"가 글 전체에 5~8회 있는가
- [ ] 느낌표가 문단당 하나꼴로 있는가
- [ ] "살짝·딱·그냥·막·생각보다"를 쓰고 있는가
- [ ] 대구("A에도, B에도")를 만들지 않았는가
- [ ] 모든 문단이 주제문으로 시작하지 않는가
- [ ] 같은 감정을 두 번 이상 굴리는 구간이 있는가
- [ ] **볼드 지시문 다음 문장이 앞말을 되풀이하고 있지 않은가**
- [ ] **소제목에 쓴 말을 본문 첫 문장에서 또 쓰지 않았는가**
- [ ] **"이게 정답이에요 / 이거 하나면 됩니다" 류가 남아 있지 않은가**
- [ ] **좋다고 말하면서 리뷰를 인용하고 있지 않은가**
- [ ] **부연·단서를 괄호로 넣을 수 있는데 문장으로 늘어놓지 않았는가**
- [ ] **문장을 쪼개기만 하고 개수는 그대로 두지 않았는가**
