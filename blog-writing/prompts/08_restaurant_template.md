# 맛집 리뷰 템플릿 + 인터뷰 질문지

네이버 맛집 후기 26편 실측 (2026-09-04). 상품 리뷰와 다른 점만 정리.
문장·어미·AI 티 규칙은 [07_writing_style.md](07_writing_style.md)를 그대로 따른다.

---

## A. 맛집 글은 이게 다르다

| 항목 | 상품 리뷰 | **맛집 리뷰** |
|---|---|---|
| 평균 분량 | 2,000~2,600자 | **2,173자** (비슷) |
| 문장 중앙값 | 17~19자 | **17자** (동일) |
| **!** | 3.9~8.3 | **8.6** (최다) |
| **~** | 1.5 | **3.2** (2배) |
| **이모지** | 6~8 | **10.3** (제일 많음) |
| ㅎㅎ | 0.7 | 1.2 |
| ~습니다 | 3.7~6.2 | **2.9** (더 구어체) |

**맛집 글이 제일 가볍고 감정적이다.** 느낌표·물결·이모지를 아끼지 말 것.

## B. 필수 정보 9가지 (몇 %의 글에 있나)

| 정보 | 수록률 | 비고 |
|---|---|---|
| **맛 묘사** | **100%** | 없으면 글이 아님 |
| **분위기·좌석** | **92%** | |
| **영업시간·휴무** | **88%** | 라스트오더·브레이크타임까지 |
| **주소·위치** | **85%** | "몇 번 출구에서 도보 몇 분"이 기본 |
| **웨이팅·예약** | **85%** | 몇 분 기다렸는지 |
| **메뉴판·가격** | 81% / 73% | 시킨 것 가격은 반드시 |
| **주차** | **69%** | 이게 생각보다 중요 |
| 재방문 의사 | 23% | 있으면 좋고 |

→ **주차·웨이팅이 각각 69%, 85%인 게 포인트.** 상품 리뷰엔 없는 축이다.
가려는 사람이 제일 궁금해하는 실무 정보다.

## C. 구조 템플릿

```
1. 도입 — 왜 갔는지 (2~3줄)
   "오빠랑 데이트할 겸 오랜만에 성수동에 왔어요ㅎㅎ"
   "친구랑 성수역 근처에서 '오늘 뭐 먹지?' 고민하며"

2. 위치·외관 — 몇 번 출구 도보 몇 분, 찾기 쉬운지

3. 웨이팅 — 몇 시에 갔고 얼마나 기다렸는지 (없었으면 "없었어요"도 정보)

4. 내부 — 좌석 수, 테이블 간격, 혼밥 가능 여부, 화장실

5. 메뉴·가격 — 시킨 것 이름과 가격 (표로)

6. ★ 맛 — 글의 절반. 음식별로 나눠서

7. 아쉬운 점 — 1~2개. 없으면 신뢰가 떨어진다

8. 이런 사람한테 추천 / 재방문 의사

9. 정보 정리 — 주소·영업시간·주차·전화 (표)

10. 해시태그 12~15개 (지역명 조합 필수)
```

### 해시태그 공식
```
#성수동맛집 #성수맛집 #성수역맛집 #성수동데이트 #성수동핫플
#{가게명} #{가게명}메뉴 #{가게명}웨이팅 #{메뉴명}맛집
#성수동내돈내산 #내돈내산맛집
```
**지역명 × (맛집/데이트/핫플/점심/저녁) 조합**이 기본이고, 가게명 단독 태그도 넣는다.

## D. 인터뷰 질문지

글 쓰기 전에 아래를 물어본다. **답을 못 하는 항목은 비워두고 글에서도 뺀다. 지어내지 않는다.**

### 1. 기본 (필수)
- 가게 이름이랑 어디예요? (지역/역 기준)
- 언제 갔어요? (요일·시간대)
- 누구랑 갔어요?
- 왜 거길 갔어요? (검색해서 / 지나가다 / 추천받아서 / 재방문)

### 2. 도착까지
- 역에서 얼마나 걸렸어요? 찾기 쉬웠나요?
- **주차** 됐어요? (주차장 유무, 발렛, 근처 공영주차장)
- **웨이팅** 있었어요? 몇 분 정도?
- 예약하고 갔어요? 예약이 되는 곳인가요?

### 3. 안에 들어가서
- 자리는 어땠어요? (테이블 수, 간격, 좌석 종류)
- 혼밥/단체 가능해 보였어요?
- 분위기 한 줄로 하면?

### 4. 먹은 것 ★ 제일 중요
- **뭐 시켰어요? 각각 얼마였어요?**
- 어떤 순서로 나왔어요? 얼마나 걸렸어요?
- **제일 맛있었던 거 하나만 꼽으면?** 어떤 맛이었어요?
  (식감·온도·간·향 중 뭐가 인상적이었는지)
- 별로였던 건 없었어요?
- 양은 어땠어요? (2인 기준 충분했는지)
- 반찬이나 서비스 있었어요?

### 5. 마무리
- **아쉬웠던 점 하나만** 꼽으면요?
- 또 갈 거예요? 간다면 뭘 시킬 거예요?
- 누구랑 가면 좋을 것 같아요? (데이트/가족/혼밥/회식)
- 팁 있어요? (이 시간에 가라, 이건 꼭 시켜라)

### 6. 사진
- 찍은 사진 뭐뭐 있어요? (외관/내부/메뉴판/음식/영수증)

## E. 살 붙일 때 지켜야 할 것

1. **안 물어본 건 안 쓴다.** 맛 묘사를 상상해서 늘리지 말 것 (07의 F-8)
2. **답변 한 줄 → 문단 하나**가 기본 배율. 그 이상 부풀리면 티 난다
3. **아쉬운 점은 반드시 넣는다.** 없으면 협찬 글로 보인다
4. 가격은 **본인이 낸 금액** 그대로. 추정 금지
5. 영업시간·주차는 확인 안 됐으면 **"확인 필요"로 남기고 넘어간다.** 틀리면 신뢰가 무너진다
6. 맛 묘사는 **비교로**. "맛있었어요"가 아니라 "생각보다 안 짰어요", "겉은 바삭한데 속은 촉촉"
