# 최종 출력 프롬프트 (범용 출력 포맷)

편집장이 최종 선정한 초안(또는 통합본)을 바탕으로 아래 포맷에 맞춰 완성본을 출력하세요.

---

## 1. 제목 후보 (3~5개)

### 조건:
- 메인 키워드 1개 이상 반드시 자연스럽게 포함
- **25자 내외** (모바일 네이버 검색 결과에서 말줄임표 없이 노출)
- 직접적 광고성 문구 금지 ("역대급", "강추", "인생템" 등 배제)
- 독자의 궁금증, 팁, 페인포인트를 자극하는 실전형 후킹 문구

```markdown
1. [메인 제목 (추천)]
2. [의문/질문형 제목]
3. [가성비/비교형 제목]
4. [상황/실사용 중심 제목]
5. [정보성 큐레이션 제목]
```

---

## 2. 본문 전문

- 완성된 본문 전체를 출력하세요.
- 단락을 자주 끊고, `07_writing_style.md` 문체 가이드(중앙값 20자 미만 문장, 어미 혼용, 적절한 이모지)를 철저히 지키세요.
- 글 끝에 `(공백 포함 총 XXXX자)`를 명시하세요.

---

## 3. 사진 삽입 가이드

본문 흐름에 맞추어 실제 다운로드된 이미지(screenshot_*.png)의 삽입 위치와 캡션을 지정하세요.

| 위치 | 사진 파일 | 캡션 / alt 텍스트 가이드 |
|---|---|---|
| 도입부 직후 | screenshot_1.png | 제품 패키지 및 전체적인 첫인상 |
| 원물/제형 설명부 | screenshot_2.png | 세부 디테일 또는 성분/스펙 인증 부분 |
| 실사용/활용부 | screenshot_3.png | 실제 조리/사용/비교 장면 |
| 마무리/주의사항 | screenshot_4.png | 보관법, 라벨, 구매 옵션 안내 등 |

※ 최소 3장 이상, 본문의 맥락과 일치하는 위치에 지정할 것.

---

## 4. 네이버 블로그 태그 (10~15개)

### 조건:
- 메인 키워드, 서브 키워드, 카테고리 일반 명사, 상황/시즌 키워드 고루 포함
- 네이버 블로그 스마트에디터에 바로 붙여넣을 수 있는 `#태그` 형식

```markdown
#메인키워드 #서브키워드 #상품명 #카테고리 #제철키워드 #상황별키워드 #내돈내산 #후기 #가격비교 #추천
```
