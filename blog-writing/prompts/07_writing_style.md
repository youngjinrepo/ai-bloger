## A. 숫자로 지킬 것

네 카테고리가 거의 똑같이 나온 값들이다. 편차가 없다는 건 이게 한국어 블로그의 기본형이라는 뜻.

| 항목 | 실측값 | 규칙 |
|---|---|---|
| **문장 길이 중앙값** | 17~19자 | 절반은 20자 미만으로 |
| 문장 하위 10% | 6~8자 | 아주 짧은 문장을 계속 섞는다 |
| 문장 상위 90% | 36~41자 | 40자 넘으면 자른다 |
| **문단 길이 중앙값** | **19자** | 한 문단 = 한두 문장. 문단을 자주 끊는다 |
| 글 전체 분량 | 2,000~2,600자 | |

가장 흔한 실수: 문장을 쪼개놓고 **개수는 그대로 두는 것.** 쪼개는 게 아니라 할 말을 줄이는 거다.

## B. 어미는 섞어 쓴다

| 어미 | 글당 횟수 | 비고 |
|---|---|---|
| **~습니다** | **3.7 ~ 6.2** | 여전히 제일 많다 |
| **~더라고요 / ~더라구요** | **1.4 ~ 1.8** | 구어체 중 1위 |
| ~있어요 | 0.7 ~ 1.6 | |
| ~이에요 / ~예요 | 0.8 ~ 1.9 | |
| ~같아요 | 0.5 ~ 1.6 | |
| ~죠 | 0.6 ~ 1.0 | |

**중요**: 100% 구어체가 아니다. "~습니다"가 여전히 최다 사용이고, 거기에 "~더라고요"를 뿌리는 구조다.
전부 구어체로 바꾸면 오히려 어색해진다.

"~더라고요"는 **단정하지 않고 겪어보니 그렇더라**로 흘리는 장치. 글당 2회 안팎이면 충분하다.

## E. 구조

**도입** — 거의 전부 이 순서다.
```
① "안녕하세요" 또는 상황 고백으로 시작
② 왜 이걸 찾게 됐는지 (불편함·가격·고민)
③ 그래서 샀다
```
실제 사례:
```
저희 아들만 그런가요? 차에서 우유 먹다가 우유팩을 콱 짜서...
남편이 제습기 제습기 노래를 부르다가 사온 제습기
이번에 휴가때 어디 멀리 나가지 않고 집에만 있으려니 조금 아쉽더라고요.
```

**본문** — 리스트 기호줄이 글당 3.5~7.9회. 불릿을 아끼지 않는다.

**신뢰 장치** — "내돈내산"이 글당 0.6~2.4회. 제목에도 자주 들어간다.

**마무리** — 짧은 인사나 추천 한 줄로 끝. 그리고 **해시태그 10~15개.**
```
재구입 의사 있습니다
이런 식으로 차려보는 것도 정말 추천합니다 :)
```

## F-0. 이건 파는 글이다 (제일 먼저 확인)

2026-09-04 실측: 순방문자는 6월 1,017 → 8월 857로 **16%** 줄었는데
클릭은 **절반 이하**로 떨어졌다. 유입 문제가 아니라 **클릭률 문제**였다.

원인을 글에서 찾아보니 이랬다.

| 글 | 시기 | 본문 글자수 | 상품명 언급 | 구매유도 표현 |
|---|---|---|---|---|
| 4789165513 | 6월 | 4,861 | - | 1 |
| 11848912669 | 6월 | 3,681 | - | 3 |
| 우니 | 8월 | 3,894 | 1 | **0** |
| 꽃게 | 9월 | 2,686 | **0** | **0** |

꽃게 글엔 **판매가 29,900원도, 판매처 이름도 본문에 없었다.**
읽고 나면 "몽당이 이득이구나"만 남고 클릭할 이유가 없다.

**F-1~F-8(AI 티 지우기)을 하다가 파는 문장까지 같이 지운 결과다.**
문체를 다듬는 건 좋은데, 아래 네 가지는 지우면 안 된다.

### 필수 4가지

1. **본문에 실제 판매가를 쓴다.** 할인폭·추가금 말고 **최종 결제가**. 단, 네이버플러스 멤버십 유무나 쿠폰 적용에 따라 결제 금액이 달라지는 경우 '보통 3만 원대 안팎(멤버십이나 쿠폰 따라 상이)'처럼 유연한 범위를 병기한다.
2. **상품명·판매처를 본문에 최소 1회** 쓴다. 뭘 파는 글인지 알 수 있어야 한다
3. **링크를 본문 중간에도 배치한다.** 맨 끝은 끝까지 읽은 사람만 본다.
   "지금 사고 싶어진 지점"(비교표 바로 아래, 가성비 옵션 소개 직후)에 하나 더
4. **마무리에 행동 문장을 남긴다.** 정보로 끝내지 않는다

```
✗ 찔 땐 18분입니다.                          (정보로 끝남)
○ 저는 몽당으로 시켰어요 🦀
  🔗 더꽃게 제철 꽃게 1kg — [최저 11,900원부터 보러가기]
```

실제 블로그 코퍼스의 마무리:
```
구매는 위 링크에서 하시면 됩니다요ㅎㅎ
할인쿠폰 받으러가기
재구입 의사 있습니다
```

### 각도를 정할 때

**정보 검색 ≠ 구매 검색.**
`몽당꽃게가 뭔지`를 검색하는 사람은 알아보는 단계다. `숫꽃게 1kg 가격`은 사기 직전이다.
정보성 각도로 유입을 끌면 클릭은 안 나온다.

→ `discover.py`도 이 기준으로 점수를 매긴다 (구매의도 접미어 +1.5 / 정보성만 있으면 -2)

## F. AI 티 지우기

숫자를 다 맞춰도 이게 남으면 티가 난다.

### F-1. 내가 말해놓고 내가 밑줄 긋지 마라

지시문을 던져놓고 한 번 더 도장을 찍는 습관. 앞 문장은 이미 완결돼 있다.

```
✗ 전날 밤에 냉장실로 옮기세요. 이게 정답이에요.
✗ 덜 풀리면 식감이 안 나와요. 완전히 풀렸을 때가 진짜입니다.
✗ 소제목 "해동, 이게 8할" → 본문 첫 줄 "해동에서 갈립니다"
```

블랙리스트:
```
이게 정답이에요 / 이거 하나면 됩니다 / 이게 핵심입니다
~가 진짜입니다 / 이 정도예요 / 결론은 ~입니다
제일 궁금한 게 이거잖아요
```

> 볼드로 지시문을 쓰면 **바로 다음 문장에는 새 정보만** 넣는다.
> 소제목에 쓴 말은 본문 첫 문장에서 다시 쓰지 않는다.

### F-2. 자랑할 때 리뷰 인용하지 마라

좋다고 주장하면서 후기를 끌어오면 남의 말이 된다. 이유 설명("~하거든요")도 대부분 뺄 수 있다.

```
✗ 손님 올 때는 상이 확 삽니다. 목판에 올려두면 모양이 그럴듯하거든요.
  리뷰에도 "여느 이자카야 못지않았다"는 후기가 있더라고요.
○ 손님 올 때도 좀 있어보이고, 색다른 메뉴라 반응도 좋더라구요.
```
단, **단점을 말할 때의 인용은 근거가 되므로 예외.**

### F-3. 부연·단서는 괄호로

```
✗ 100g이면 열 조각 안팎이에요. 근데 개수를 세서 담는 게 아니라 중량 기준이라,
  알 크기 따라 그때그때 살짝 달라지더라고요.
○ 100g이면 열 조각 안팎이에요.
  (개수를 세서 담는 게 아니라 중량 기준이라 그때그때 살짝 달라집니다)
```

### F-4. 대구를 만들지 마라

"A에도, B에도" 같은 대칭은 사람이 잘 안 쓴다.
```
✗ 혼자 마실 때도, 손님 올 때도
○ 혼술 안주로, 그리고 손님상에
```

### F-5. 관용구를 쓰면 설명이 통째로 없어진다

```
참 쉽죠?  /  안 어울리는 데가 없습니다  /  손이 계속 가더라고요
```

### F-6. 모든 문단을 주제문으로 시작하지 마라

정보가 0인 문장으로 여는 것도 사람 티다. ("감이 잘 안 오시죠?")
단, 같은 말을 두 번 하게 되면 빼야 한다.

### F-7. 명사로 끝내지 마라 (서술어를 붙여라)

문장을 짧게 쓰려다 **서술어까지 잘라버리는** 습관. 간결하고 리듬이 살아 보여서 자꾸 쓰게 되는데,
이게 "글로 쓴 티"를 낸다. 말할 때는 아무도 이렇게 말하지 않는다.

```
✗ 상견례, 시댁, 윗분. 한 분께 제대로 드리는 자리요.
○ 상견례나 중요한 분께 선물 드릴 때 제일 괜찮아요.

✗ 참기름 한 병, 들기름 한 병. 딱 그것뿐입니다.
○ 참기름 한 병하고 들기름 한 병이 들어 있습니다.

✗ 원산지요.
○ 원산지를 보세요.

✗ 여러 명이면 ①, 거래처면 ②, 어른 한 분이면 ③.
○ 여러 명한테 돌릴 거면 ①, 거래처에 보낼 거면 ②, 어른 한 분께 드릴 거면 ③이 낫습니다.
```

특히 조심할 형태:

```
~자리요 / ~쪽이요 / ~경우요        (명사 + 요)
~뿐입니다 / ~것뿐이에요            (체언 종결)
명사, 명사, 명사.                  (나열만 하고 서술어 없음)
```

> **규칙**: 문장이 명사나 명사구로 끝나면 서술어를 붙인다.
> "짧게 쓴다"는 건 할 말을 줄이는 것이지(F-8 참고), 서술어를 자르는 게 아니다.

### F-8. 안 물어본 부연을 붙이지 마라

문장에 리듬이나 생활감을 넣으려고 **묻지도 않은 정황을 덧붙이는** 습관.
정보 가치가 0이고 독자는 궁금해하지 않는다. 소설적 디테일이 아니라 군더더기다.

```
✗ 가을이라 꽃게 시켰습니다. 쪄먹고 남으면 탕 끓이려고요
○ 가을이라 꽃게 시켰습니다

✗ 명절 선물로 참기름을 골랐어요. 부모님 댁에 하나, 시댁에 하나 보내려고요
○ 명절 선물로 참기름을 골랐어요
```

사람은 자기 계획을 굳이 설명하지 않는다. 필요하면 나중에 나온다.

> **규칙**: 한 문장을 지웠을 때 독자가 아쉬워하지 않으면 지운다.
> 특히 도입부의 "~하려고요", "~할 예정이에요" 류를 의심할 것.

### F-9. 가짜 '내돈내산' 체험을 지어내지 마라 (객관적 분석체 유지)

실제로 직접 구매해 사용한 것이 아니라면, 제목에 `내돈내산`을 넣거나 본문에 가짜 1인칭 체험("직접 사서 발라봤습니다", "돈 아끼고 나니 속이 시원합니다")을 쓰지 않는다.
독자는 가짜 후기를 귀신같이 알아채며, 적발 시 신뢰도가 추락한다.

```
✗ 제목: 밀본 염색약 올디브보떼 내돈내산 후기
  본문: 직접 사서 발라봤습니다. 6만 원 아끼고 나니 속이 다 시원하네요.
○ 제목: 밀본 염색약 올디브보떼, 밝은 새치커버 실패하는 이유 딱 정리
  본문: 실제 실패 후기들을 꼼꼼히 분석해 봤습니다. 왜 실패하는지 원인과 해결법을 짚어드릴게요.
```

> **규칙**: 직접 쓴 게 아니면 **수만 건의 실제 리뷰와 1~3점 불만을 정밀 분석한 '객관적 팩트체크 및 가이드'** 톤을 철저히 유지한다.

### F-10. 오바하는 홈쇼핑식 마케팅 문구를 쓰지 마라

가격을 방어하거나 장점을 어필하려다 과장된 홈쇼핑/세일즈 수식어를 남발하는 습관. 읽는 순간 광고 냄새가 진동한다.

```
✗ 산화제 따로 사도 커피 한 잔 값? (가격 저항 제로) 전혀 그렇지 않습니다!
○ 산화제가 안 와서 낭패 본 이유 (본품이 4,930원으로 워낙 저렴해 산화제를 추가해도 마트 염색약보다 부담 없는 가격대입니다)
```

블랙리스트:
```
가격 저항 제로 / 커피 한 잔 값? / 전혀 그렇지 않습니다!
역대급 / 대박 / 인생템 / 품절 대란
```

> **규칙**: 저렴한 점을 어필할 때도 감정을 싣지 말고 **숫자와 팩트만 차분하게 제시**한다.

### F-11. 세부 호수/스펙 키워드를 본문과 해시태그에 반드시 심어라

실제 구매 직전의 검색 유입은 모호한 상위 키워드("새치염색약 추천")가 아니라 **구체적인 호수나 모델명(`b6`, `b7-NB`, `b8-NB`)**에서 터진다.

> **규칙**: 구매자가 결제 직전 고민하는 **세부 호수/색상/스펙**을 본문 1번 섹션에 명확히 대비시키고, 해시태그에도 반드시 포함한다.

- [ ] 링크를 **본문 중간에도** 배치했는가
- [ ] 마무리가 정보가 아니라 **행동 문장**으로 끝나는가

**숫자**
- [ ] 문장 중앙값 20자 아래인가
- [ ] 한 문단이 한두 문장인가
- [ ] "~습니다"와 "~더라고요"를 섞었는가 (전부 구어체로 만들지 않았는가)
- [ ] "~더라고요"가 2회 안팎 있는가
- [ ] 느낌표가 문단당 하나꼴인가
- [ ] 이모지를 넣었는가 (소제목·리스트 앞)
- [ ] 카테고리에 맞게 ㅋㅋ·ㅠㅠ 수위를 조절했는가 (D표)

**AI 티 & 신뢰도**
- [ ] **가짜 '내돈내산' 표기나 허위 직접 체험 서술이 없는가 (F-9)**
- [ ] **'가격 저항 제로' 등 오바하는 마케팅/홈쇼핑투가 없는가 (F-10)**
- [ ] **세부 호수/스펙 키워드가 본문과 해시태그에 반영되었는가 (F-11)**
- [ ] 볼드 지시문 다음 문장이 앞말을 되풀이하지 않는가
- [ ] 소제목에 쓴 말을 본문 첫 문장에서 또 쓰지 않았는가
- [ ] "이게 정답이에요" 류가 남아 있지 않은가
- [ ] 좋다고 말하면서 리뷰를 인용하고 있지 않은가
- [ ] 부연을 괄호로 넣을 수 있는데 문장으로 늘어놓지 않았는가
- [ ] 대구를 만들지 않았는가
- [ ] **문장이 명사로 끝나고 있지 않은가 (서술어를 붙였는가)**
- [ ] **안 물어본 부연("~하려고요")을 붙이지 않았는가**
- [ ] 문장을 쪼개기만 하고 개수는 그대로 두지 않았는가

**구조**
- [ ] 도입이 상황 고백 → 고민 → 그래서 샀다(또는 분석했다) 순인가
- [ ] 해시태그 10~15개를 넣었는가 (세부 키워드 포함)
